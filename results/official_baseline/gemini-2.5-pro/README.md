# Official Track 2 Baseline Evaluation Results

This directory contains aggregate evaluation results for the audio generated by the official Track 2 baseline (`track2_submission_base.zip`). The audio was evaluated with the Codabench-compatible Track 2 evaluation program using Gemini 2.5 Pro as the LALM judge.

## Files

- `scores.json`: Chinese, English, and final bilingual Track 2 scores.
- `detailed_results.json`: mean A/P/N/Q/E component scores, sample counts, error counts, normalized values, weights, and aggregate scores.

## Evaluation Summary

- Evaluated samples: 1,600 (800 Chinese and 800 English)
- Permanent sample errors: 0
- Scoring formula: `100 * sum(weight_i * (score_i - 1) / 4)`
- Component weights: A 30%, P 25%, N 15%, Q 15%, E 15%
- Input text: the evaluator reads the reference field containing the NVV-tagged text.
