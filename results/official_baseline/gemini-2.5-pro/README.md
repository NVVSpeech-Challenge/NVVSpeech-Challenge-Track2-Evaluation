# Track 2 官方 Baseline 评测结果

本目录保存 Track 2 官方 Baseline 生成音频（`track2_submission_base.zip`）的汇总评测结果。评测使用 Codabench 兼容版 Track 2 评测程序，LALM 评委模型为 Gemini 2.5 Pro。

## 文件说明

- `scores.json`：中文、英文以及中英双语最终 Track 2 得分。
- `detailed_results.json`：A/P/N/Q/E 五项指标的平均分，以及样本数量、错误数量、归一化分数、指标权重和综合得分。

## 评测说明

- 评测样本数：1,600 条，其中中文 800 条、英文 800 条
- 永久失败样本数：0
- 计分公式：`100 * sum(weight_i * (score_i - 1) / 4)`
- 指标权重：A 30%、P 25%、N 15%、Q 15%、E 15%
- 输入文本：评测程序读取参考数据中带有 NVV 标签的文本字段。
